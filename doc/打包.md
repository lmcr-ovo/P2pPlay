# Qt Windows 程序打包笔记

目标：把本项目编译成可以在没有 Qt、没有 CLion、没有配置环境变量的 Windows 电脑上运行的 exe。

核心流程：

```text
1. 用 MinGW 编译 Release 版 exe
2. 把 exe 复制到发布目录
3. 用 windeployqt 复制 Qt 运行库
4. 手动补齐 MinGW 运行库
5. 把整个发布目录发给别人
```

不要只发一个 exe。Qt 程序通常还需要 `Qt5Core.dll`、`Qt5Network.dll`、MinGW 运行库等文件。

## 1. 清理旧构建目录

如果之前配置失败过，先删除旧目录，避免 CMake 缓存继续影响后续构建。

```bat
cd /d D:\CODE\C++\qt\P2Pplay
rmdir /s /q cmake-build-release
```

## 2. 配置 Release 构建

本项目使用 Qt MinGW，所以要明确指定 `MinGW Makefiles`，不要让 CMake 默认选择 `NMake Makefiles`。

```bat
"D:\CLion 2019.3.6\bin\cmake\win\bin\cmake.exe" ^
-S . ^
-B cmake-build-release ^
-G "MinGW Makefiles" ^
-DCMAKE_BUILD_TYPE=Release ^
-DCMAKE_PREFIX_PATH=D:/Qt5/5.14.0/mingw73_64 ^
-DCMAKE_C_COMPILER=D:/Qt5/Tools/mingw730_64/bin/gcc.exe ^
-DCMAKE_CXX_COMPILER=D:/Qt5/Tools/mingw730_64/bin/g++.exe
```

注意路径里给 CMake 的参数建议使用 `/`，例如：

```text
D:/Qt5/Tools/mingw730_64/bin/g++.exe
```

不要写成：

```text
D:\Qt5\Tools\mingw730_64\bin\g++.exe
```

因为 CMake 可能把 `\Q` 之类的内容当成非法转义。

## 3. 编译目标

编译客户端：

```bat
"D:\CLion 2019.3.6\bin\cmake\win\bin\cmake.exe" --build cmake-build-release --target testP2pClient -j 4
```

编译服务端 Windows 版：

```bat
"D:\CLion 2019.3.6\bin\cmake\win\bin\cmake.exe" --build cmake-build-release --target testP2pServer -j 4
```

生成位置：

```text
cmake-build-release\Client\test\testP2pClient.exe
cmake-build-release\Server\test\testP2pServer.exe
```

## 4. 创建发布目录

客户端：

```bat
rmdir /s /q release-client
mkdir release-client
copy "cmake-build-release\Client\test\testP2pClient.exe" "release-client\"
```

服务端：

```bat
rmdir /s /q release-server
mkdir release-server
copy "cmake-build-release\Server\test\testP2pServer.exe" "release-server\"
```

路径里有 `C++`，所以建议所有路径都加双引号。

## 5. 使用 windeployqt

客户端：

```bat
"D:\Qt5\5.14.0\mingw73_64\bin\windeployqt.exe" --release "release-client\testP2pClient.exe"
```

服务端：

```bat
"D:\Qt5\5.14.0\mingw73_64\bin\windeployqt.exe" --release "release-server\testP2pServer.exe"
```

这里建议加 `--release`。有时 `windeployqt` 会把 exe 误判成 debug executable，然后去找：

```text
Qt5Cored.dll
Qt5Networkd.dll
```

但普通 Qt 安装里通常只有 Release 运行库：

```text
Qt5Core.dll
Qt5Network.dll
```

所以如果确认自己编译的是 Release 版，可以直接使用 `--release`。

## 6. 补齐 MinGW 运行库

`windeployqt` 主要负责 Qt 运行库，但 MinGW 的运行库建议手动复制。

客户端：

```bat
copy "D:\Qt5\Tools\mingw730_64\bin\libgcc_s_seh-1.dll" "release-client\"
copy "D:\Qt5\Tools\mingw730_64\bin\libstdc++-6.dll" "release-client\"
copy "D:\Qt5\Tools\mingw730_64\bin\libwinpthread-1.dll" "release-client\"
```

服务端：

```bat
copy "D:\Qt5\Tools\mingw730_64\bin\libgcc_s_seh-1.dll" "release-server\"
copy "D:\Qt5\Tools\mingw730_64\bin\libstdc++-6.dll" "release-server\"
copy "D:\Qt5\Tools\mingw730_64\bin\libwinpthread-1.dll" "release-server\"
```

## 7. 发布目录应该长什么样

客户端发布目录大概会变成：

```text
release-client/
  testP2pClient.exe
  Qt5Core.dll
  Qt5Network.dll
  libgcc_s_seh-1.dll
  libstdc++-6.dll
  libwinpthread-1.dll
```

如果以后项目使用 GUI，还可能出现：

```text
platforms/
styles/
imageformats/
Qt5Gui.dll
Qt5Widgets.dll
```

发布时要把整个 `release-client` 文件夹发给别人，而不是只发 exe。

## 8. 运行测试

客户端 Host：

```bat
release-client\testP2pClient.exe host Alice 服务器公网IP 9000 9001 10000
```

客户端 Guest：

```bat
release-client\testP2pClient.exe guest Bob 房间号 服务器公网IP 9000 9001 10001
```

服务端 Windows 版：

```bat
release-server\testP2pServer.exe 0.0.0.0 9000 0.0.0.0 9001
```

## 9. 常见错误

### 找不到 cl

错误：

```text
The CMAKE_C_COMPILER: cl is not a full path and was not found in the PATH.
```

原因：CMake 默认选择了 `NMake Makefiles`，它需要 Visual Studio 的 `cl.exe`。

解决：配置时指定 MinGW：

```bat
-G "MinGW Makefiles"
```

并指定：

```bat
-DCMAKE_C_COMPILER=D:/Qt5/Tools/mingw730_64/bin/gcc.exe
-DCMAKE_CXX_COMPILER=D:/Qt5/Tools/mingw730_64/bin/g++.exe
```

### Invalid character escape '\Q'

错误：

```text
Invalid character escape '\Q'
```

原因：CMake 参数里用了 Windows 反斜杠路径：

```text
D:\Qt5\...
```

解决：改成正斜杠：

```text
D:/Qt5/...
```

### Qt5Cored.dll does not exist

错误：

```text
Qt5Cored.dll does not exist.
```

原因：`windeployqt` 把 exe 判断成 debug 版，于是去找 debug Qt 库。

解决：强制 Release 部署：

```bat
"D:\Qt5\5.14.0\mingw73_64\bin\windeployqt.exe" --release "release-client\testP2pClient.exe"
```

### 别人电脑提示缺 dll

常见缺失：

```text
Qt5Core.dll
Qt5Network.dll
libgcc_s_seh-1.dll
libstdc++-6.dll
libwinpthread-1.dll
```

解决：

```text
1. 重新运行 windeployqt
2. 手动复制 MinGW 运行库
3. 确认发给别人的是整个 release-client 目录
```
