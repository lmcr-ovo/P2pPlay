# P2pPlay 输入系统升级方案

## 目标

1. 消除可靠输入因丢包产生的统一延时。
2. 增加乱序输入缓存，支持输入包乱序到达。
3. 增加鼠标移动、按键和滚轮事件支持。
4. Host 发送归一化相对坐标。
5. Guest 根据当前视频窗口的实际显示区域还原鼠标位置。
6. Guest 发送鼠标操作时，同样使用归一化相对坐标。
7. Host 根据本机虚拟桌面尺寸还原 Guest 鼠标坐标并注入系统。
8. Guest 窗口缩放、全屏切换、分辨率变化时，不需要重新同步屏幕尺寸。
9. Guest 鼠标进入视频区域时隐藏本地光标，离开或失去焦点时恢复光标。

---

## 一、整体输入方向

### Host → Guest

Host 定时获取本机鼠标位置，并发送给 Guest：

```text
Host 当前鼠标位置
    ↓
转换为 0~65535 的归一化坐标
    ↓
发送 InputSample
    ↓
Guest 根据视频实际显示区域还原坐标
    ↓
绘制虚拟鼠标
```

Host → Guest 的鼠标位置只用于 Guest 绘制虚拟鼠标，不注入 Guest 操作系统。

### Guest → Host

Guest 在视频窗口中产生鼠标事件，并发送给 Host：

```text
Guest 视频窗口鼠标位置
    ↓
根据视频实际显示区域转换为 0~65535 的归一化坐标
    ↓
发送 InputSample
    ↓
Host 根据本机虚拟桌面尺寸还原坐标
    ↓
调用 SendInput 注入鼠标事件
```

Guest → Host 的鼠标移动事件为不可靠传输，鼠标按键和滚轮事件为可靠传输。

## 二、坐标协议

### 2.1 坐标范围

所有鼠标坐标统一使用 `0~65535` 的归一化整数：

```cpp
x ∈ [0, 65535]
y ∈ [0, 65535]
```

`InputSample::x` 和 `InputSample::y` 的语义如下：

```cpp
sample.x // 归一化 X 坐标
sample.y // 归一化 Y 坐标
```

网络协议中不直接传输：

- Host 屏幕像素坐标；
- Guest 窗口像素坐标；
- 视频编码分辨率；
- Guest 窗口分辨率。

### 2.2 坐标转换规则

归一化：

```cpp
normalized = relative / (size - 1) * 65535
```

还原：

```cpp
relative = normalized / 65535 * (size - 1)
```

坐标必须限制在合法范围内：

```cpp
normalizedX = qBound(0, normalizedX, 65535);
normalizedY = qBound(0, normalizedY, 65535);
```

### 2.3 InputCoordinate.h

建议增加统一的坐标转换工具：

```cpp
#ifndef P2PPLAY_INPUTCOORDINATE_H
#define P2PPLAY_INPUTCOORDINATE_H

#include <QtGlobal>
#include <QtMath>

namespace InputCoordinate {

constexpr qint32 Max = 65535;

inline qint32 clamp(qint32 value) {
    return qBound<qint32>(0, value, Max);
}

inline qint32 toNormalized(qreal relative, qreal size) {
    if (size <= 1.0) {
        return 0;
    }

    relative = qBound<qreal>(
        0.0,
        relative,
        size - 1.0
    );

    const qreal value =
        relative / (size - 1.0) * Max;

    return qBound<qint32>(
        0,
        qRound(value),
        Max
    );
}

inline qreal fromNormalized(qint32 normalized,
                            qreal size) {
    if (size <= 1.0) {
        return 0.0;
    }

    normalized = clamp(normalized);

    return static_cast<qreal>(normalized)
           / Max
           * (size - 1.0);
}

}

#endif // P2PPLAY_INPUTCOORDINATE_H
```

所有涉及鼠标坐标的模块都使用该工具，避免各模块重复实现换算逻辑。

## 四、InputReceiver 乱序缓存

### 4.1 设计要求

可靠输入按照 `seq` 顺序执行。

当接收到：

```text
seq == expectedSeq
```

立即执行，并继续检查缓存中的连续包。

当接收到：

```text
seq > expectedSeq
```

放入缓存，等待缺失包到达。

当接收到：

```text
seq < expectedSeq
```

认为是重复包，重新发送当前 ACK。

`MouseMove` 为不可靠事件，不参与可靠输入排序。

### 4.2 InputReceiver.h

```cpp
#ifndef P2PPLAY_INPUTRECEIVER_H
#define P2PPLAY_INPUTRECEIVER_H

#include <QObject>
#include <QHash>
#include "InputSample.h"

class InputReceiver : public QObject {
    Q_OBJECT

public:
    explicit InputReceiver(QObject* parent = nullptr);

signals:
    void inputAckSampleBytesReady(
        const QByteArray& bytes
    );

public slots:
    void onInputSampleBytesReady(
        const QByteArray& bytes
    );

private:
    static void handleKeyboard(
        const InputSample& sample
    );

    static void handleMouse(
        const InputSample& sample
    );

    static void handleSample(
        const InputSample& sample
    );

    void sendAck(quint32 ackSeq);
    void tryExecutePending();
    void flushStalePending();

private:
    quint32 expectedSeq_ = 0;

    QHash<quint32, InputSample> pendingSamples_;

    static constexpr quint32 MaxPendingSize = 50;
};

#endif // P2PPLAY_INPUTRECEIVER_H
```

### 4.3 InputReceiver.cpp

```cpp
#include "InputReceiver.h"

#include <QDebug>

#include "InputSampleCodec.h"
#include "InputInjector.h"

InputReceiver::InputReceiver(QObject* parent)
    : QObject(parent) {
}

void InputReceiver::onInputSampleBytesReady(
    const QByteArray& bytes) {

    InputSample sample;

    if (!InputSampleCodec::decode(bytes, sample)) {
        return;
    }

    if (sample.kind != InputSampleKind::Request) {
        return;
    }

    // MouseMove 为高频不可靠事件，直接执行
    if (!isReliableInputAction(sample.action)) {
        handleSample(sample);
        return;
    }

    if (sample.seq < expectedSeq_) {
        // 重复包，回复最近一次已执行序号
        sendAck(
            expectedSeq_ == 0
                ? 0
                : expectedSeq_ - 1
        );
        return;
    }

    if (sample.seq == expectedSeq_) {
        handleSample(sample);
        ++expectedSeq_;

        tryExecutePending();
        return;
    }

    // seq > expectedSeq_，缓存乱序包
    if (!pendingSamples_.contains(sample.seq)) {
        pendingSamples_.insert(sample.seq, sample);
    }

    if (pendingSamples_.size() > MaxPendingSize) {
        flushStalePending();
    } else {
        sendAck(
            expectedSeq_ == 0
                ? 0
                : expectedSeq_ - 1
        );
    }
}
```

### 4.4 执行连续缓存包

```cpp
void InputReceiver::tryExecutePending() {
    while (pendingSamples_.contains(expectedSeq_)) {
        const InputSample sample =
            pendingSamples_.take(expectedSeq_);

        handleSample(sample);
        ++expectedSeq_;
    }

    sendAck(
        expectedSeq_ == 0
            ? 0
            : expectedSeq_ - 1
    );
}
```

### 4.5 缓存溢出处理

当缓存超过最大数量时，说明中间某个序号可能永久丢失。此时跳过缺失序号，从缓存中最小的序号继续执行。

```cpp
void InputReceiver::flushStalePending() {
    if (pendingSamples_.isEmpty()) {
        return;
    }

    auto it = pendingSamples_.constBegin();
    quint32 minSeq = it.key();

    for (; it != pendingSamples_.constEnd(); ++it) {
        minSeq = qMin(minSeq, it.key());
    }

    qWarning()
        << "[InputReceiver] pending buffer overflow,"
        << "skip expected seq from"
        << expectedSeq_
        << "to"
        << minSeq;

    expectedSeq_ = minSeq;
    tryExecutePending();
}
```

### 4.6 输入分发

```cpp
void InputReceiver::handleSample(
    const InputSample& sample) {

    switch (sample.device) {
        case InputDevice::Keyboard:
            handleKeyboard(sample);
            break;

        case InputDevice::Mouse:
            handleMouse(sample);
            break;

        default:
            break;
    }
}
```

### 4.7 键盘处理

```cpp
void InputReceiver::handleKeyboard(
    const InputSample& sample) {

    if (sample.action == InputAction::KeyDown) {
        InputInjector::sendKeyDown(sample.vk);
    } else if (sample.action == InputAction::KeyUp) {
        InputInjector::sendKeyUp(sample.vk);
    }
}
```

### 4.8 鼠标处理

```cpp
void InputReceiver::handleMouse(
    const InputSample& sample) {

    switch (sample.action) {
        case InputAction::MouseMove:
            InputInjector::sendMouseMove(
                sample.x,
                sample.y
            );
            break;

        case InputAction::MouseDown:
            InputInjector::sendMouseDown(
                sample.mouseButton
            );
            break;

        case InputAction::MouseUp:
            InputInjector::sendMouseUp(
                sample.mouseButton
            );
            break;

        case InputAction::MouseWheel:
            InputInjector::sendMouseWheel(
                sample.wheelDelta
            );
            break;

        default:
            break;
    }
}
```

### 4.9 ACK

```cpp
void InputReceiver::sendAck(quint32 ackSeq) {
    InputSample ackSample;
    ackSample.kind = InputSampleKind::Ack;
    ackSample.ackSeq = ackSeq;

    emit inputAckSampleBytesReady(
        InputSampleCodec::encode(ackSample)
    );
}
```


### 5.2 鼠标移动注入

```cpp
#include "InputInjector.h"

#include <windows.h>

#include "InputCoordinate.h"

void InputInjector::sendMouseMove(
    qint32 normalizedX,
    qint32 normalizedY) {

    normalizedX =
        InputCoordinate::clamp(normalizedX);

    normalizedY =
        InputCoordinate::clamp(normalizedY);

    INPUT input{};
    input.type = INPUT_MOUSE;

    input.mi.dx =
        static_cast<LONG>(normalizedX);

    input.mi.dy =
        static_cast<LONG>(normalizedY);

    input.mi.dwFlags =
        MOUSEEVENTF_ABSOLUTE |
        MOUSEEVENTF_VIRTUALDESK |
        MOUSEEVENTF_MOVE;

    SendInput(
        1,
        &input,
        sizeof(INPUT)
    );
}
```

`MOUSEEVENTF_VIRTUALDESK` 用于支持 Windows 虚拟桌面区域，包括多显示器和负坐标场景。

### 6.1 可靠动作

```text
KeyUp
```

### 6.2 不可靠动作

### 6.3 InputSender.cpp

```cpp
void InputSender::onInputRawSampleReady(
    const InputSample& rawSample) {

    InputSample sample = rawSample;

    sample.seq = nextSeq_++;
    sample.timeStampMs =
        QDateTime::currentMSecsSinceEpoch();

    if (isReliableInputAction(sample.action)) {
        waitToBeAck_.push_back(sample);
    }

    emit inputSampleBytesReady(
        InputSampleCodec::encode(sample)
    );
}
```

鼠标移动事件虽然分配序号，但不加入待确认队列。这样可以复用现有编码结构，同时避免高频鼠标移动占用重传队列。

### 7.4 视频窗口坐标转换为归一化坐标

```cpp
QPoint VideoWidget::mapToNormalized(
    const QPoint& widgetPos) const {

    const QRect drawRect = videoDrawRect();

    if (drawRect.isEmpty()) {
        return QPoint(0, 0);
    }

    // 将黑边区域的坐标限制到视频区域边界
    const int x = qBound(
        drawRect.left(),
        widgetPos.x(),
        drawRect.right()
    );

    const int y = qBound(
        drawRect.top(),
        widgetPos.y(),
        drawRect.bottom()
    );

    const qreal relativeX =
        static_cast<qreal>(
            x - drawRect.left()
        );

    const qreal relativeY =
        static_cast<qreal>(
            y - drawRect.top()
        );

    return QPoint(
        InputCoordinate::toNormalized(
            relativeX,
            drawRect.width()
        ),
        InputCoordinate::toNormalized(
            relativeY,
            drawRect.height()
        )
    );
}
```

### 7.5 归一化坐标转换为视频窗口坐标

```cpp
QPointF VideoWidget::mapFromNormalized(
    qint32 normalizedX,
    qint32 normalizedY) const {

    const QRect drawRect = videoDrawRect();

    if (drawRect.isEmpty()) {
        return QPointF();
    }

    const qreal relativeX =
        InputCoordinate::fromNormalized(
            normalizedX,
            drawRect.width()
        );

    const qreal relativeY =
        InputCoordinate::fromNormalized(
            normalizedY,
            drawRect.height()
        );

    return QPointF(
        drawRect.left() + relativeX,
        drawRect.top() + relativeY
    );
}
```

```cpp
void InputServiceWorker::connectRoleSignals() {
    if (role_ == Role::Host) {
        roleConnections_.append(
            connect(
                &receiver_,
                &InputReceiver::
                    inputAckSampleBytesReady,
                this,
                &InputServiceWorker::
                    inputAckSampleBytesReady
            )
        );

        // Host 每 33ms 发送一次鼠标位置
        mouseSyncTimer_.setInterval(33);

        roleConnections_.append(
            connect(
                &mouseSyncTimer_,
                &QTimer::timeout,
                this,
                &InputServiceWorker::
                    sendHostMousePosition
            )
        );

        mouseSyncTimer_.start();
    } else if (role_ == Role::Guest) {
        roleConnections_.append(
            connect(
                &capture_,
                &InputCapture::
                    inputRawSampleReady,
                &sender_,
                &InputSender::
                    onInputRawSampleReady
            )

        roleConnections_.append(
            connect(
                &sender_,
                &InputSender::
                    inputSampleBytesReady,
                this,
                &InputServiceWorker::
                    inputSampleBytesReady
            )
        );
    }
}
```

## 九、Host 发送归一化鼠标位置

Host 使用 Windows 虚拟桌面区域，将鼠标像素坐标转换为归一化坐标。

```cpp
#include <windows.h>

#include "InputCoordinate.h"
#include "InputSampleCodec.h"

void InputServiceWorker::sendHostMousePosition() {
    POINT point;

    if (!GetCursorPos(&point)) {
        return;
    }

    const int virtualLeft =
        GetSystemMetrics(SM_XVIRTUALSCREEN);

    const int virtualTop =
        GetSystemMetrics(SM_YVIRTUALSCREEN);

    const int virtualWidth =
        GetSystemMetrics(SM_CXVIRTUALSCREEN);

    const int virtualHeight =
        GetSystemMetrics(SM_CYVIRTUALSCREEN);

    if (virtualWidth <= 1 ||
        virtualHeight <= 1) {
        return;
    }

    const qreal relativeX =
        static_cast<qreal>(
            point.x - virtualLeft
        );

    const qreal relativeY =
        static_cast<qreal>(
            point.y - virtualTop
        );

    InputSample sample;
    sample.kind = InputSampleKind::Request;
    sample.device = InputDevice::Mouse;
    sample.action = InputAction::MouseMove;

    sample.x = InputCoordinate::toNormalized(
        relativeX,
        virtualWidth
    );

    sample.y = InputCoordinate::toNormalized(
        relativeY,
        virtualHeight
    );

    sample.timeStampMs =
        QDateTime::currentMSecsSinceEpoch();

    // 鼠标移动为不可靠高频消息
    emit inputSampleBytesReady(
        InputSampleCodec::encode(sample)
    );
}
```

Host 不发送：

```cpp
sample.x = point.x;
sample.y = point.y;
```

而是发送转换后的归一化坐标。

## 十、Guest 鼠标事件发送

```cpp
void InputServiceWorker::onMouseInputSampleReady(
    const InputSample& sample) {

    if (role_ != Role::Guest) {
        return;
    }

    if (sample.action == InputAction::MouseMove) {
        // 高频鼠标移动直接发送
        emit inputSampleBytesReady(
            InputSampleCodec::encode(sample)
        );
    } else {
        // 鼠标按键和滚轮使用可靠传输
        sender_.onInputRawSampleReady(sample);
    }
}
```

`VideoWidget` 产生的 `MouseMove`、`MouseDown`、`MouseUp` 中，`x/y` 已经是归一化坐标，可以直接编码发送。

## 十一、输入数据接收

```cpp
void InputServiceWorker::onInputSampleBytesReceived(
    const QByteArray& bytes) {

    if (role_ == Role::Host) {
        // Host 接收 Guest 键盘和鼠标事件
        receiver_.onInputSampleBytesReady(bytes);
        return;
    }

    if (role_ != Role::Guest) {
        return;
    }

    InputSample sample;

    if (!InputSampleCodec::decode(bytes, sample)) {
        return;
    }

    if (sample.kind == InputSampleKind::Ack) {
        sender_.onInputAckSampleBytesReady(bytes);
        return;
    }

    if (sample.kind != InputSampleKind::Request) {
        return;
    }

    if (sample.device == InputDevice::Mouse &&
        sample.action == InputAction::MouseMove) {

        emit hostMousePositionReceived(sample);
    }
}
```

Guest 收到 Host 的鼠标位置后，不进入 `InputReceiver`，直接发送给 `VideoWidget` 绘制。

## 十三、输入动作可靠性

### 可靠动作

```cpp
bool isReliableInputAction(
    InputAction action) {

    switch (action) {
        case InputAction::KeyDown:
        case InputAction::KeyUp:
        case InputAction::MouseDown:
        case InputAction::MouseUp:
        case InputAction::MouseWheel:
            return true;

        case InputAction::MouseMove:
        default:
            return false;
    }
}
```

### 可靠动作处理流程

```text
InputSample
    ↓
分配 seq
    ↓
加入待确认队列
    ↓
发送
    ↓
等待 ACK
    ↓
超时重传
    ↓
收到 ACK 后移除
```

### 不可靠动作处理流程

```text
InputSample
    ↓
分配 seq
    ↓
直接发送
    ↓
不等待 ACK
    ↓
不进行重传
```

鼠标移动即使丢失，也会在下一次同步中发送最新位置。

## 十四、边界处理

### 14.1 Guest 鼠标位于黑边区域

如果 Guest 鼠标进入视频窗口的黑边区域，将坐标限制到视频实际显示区域：

```cpp
x = qBound(
    drawRect.left(),
    x,
    drawRect.right()
);

y = qBound(
    drawRect.top(),
    y,
    drawRect.bottom()
);
```

这样不会产生超出视频范围的归一化坐标。

### 14.2 空视频帧

当视频图像为空时：

```cpp
if (image_.isNull()) {
    return QPoint(0, 0);
}
```

虚拟鼠标位置在视频帧有效后重新计算。

### 14.3 坐标异常

接收端始终限制坐标：

```cpp
normalizedX =
    InputCoordinate::clamp(normalizedX);

normalizedY =
    InputCoordinate::clamp(normalizedY);
```

避免非法数据造成鼠标越界。

### 14.4 多显示器

Host 使用以下 Windows API 获取虚拟桌面：

```cpp
SM_XVIRTUALSCREEN
SM_YVIRTUALSCREEN
SM_CXVIRTUALSCREEN
SM_CYVIRTUALSCREEN
```

这样可以支持：

- 多显示器；
- 主显示器左侧或上方的显示器；
- 虚拟桌面负坐标；
- 不同显示器分辨率。

## 十七、最终协议约定

```cpp
InputSample::x = 0 ~ 65535;
InputSample::y = 0 ~ 65535;
```

坐标来源和处理方式如下：

```text
Host 鼠标位置：
    Host 虚拟桌面像素坐标
    → 归一化坐标
    → Guest 视频显示区域坐标

Guest 鼠标操作：
    Guest 视频显示区域坐标
    → 归一化坐标
    → Host 虚拟桌面像素坐标
    → SendInput
```

所有鼠标位置都必须经过归一化处理后再写入 `InputSample`。
